## 🛍️ ShopSphere – E-Commerce Web Application

ShopSphere is a web-based shopping application developed using Java technologies. It provides a shopping interface for customers and an admin panel for managing the store.

### Features

* User Registration and Login
* Product Browsing
* Shopping Cart
* Order History
* Admin Dashboard
* User, Product, Category, and Order Management
* Database Connectivity

### Technologies Used

* Java
* JSP and Servlets
* HTML, CSS, and JavaScript
* MySQL
* JDBC
* Apache Tomcat
* Maven

## 🚀 How to Run ShopSphere

1. Clone or download this repository.
2. Open the `ShopSphere` folder.
3. Configure the MySQL database using XAMPP/phpMyAdmin.
4. Update the database connection settings.
5. Build the project using Maven:

   ```bash
   mvn clean package
   ```
6. Deploy the generated WAR file to Apache Tomcat.
7. Start Tomcat and open the application in your browser.
